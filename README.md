# NeoForge服务器搭建：从 Java 环境到一键开服，新手也能跑通的模组服联机方案

搜「NeoForge服务器搭建」的人，卡住的地方通常不是不会下 mod，而是不知道第一步该干嘛：Java 装哪个版本、安装器跑完之后为什么闪退、服务端加载器到底该选 Forge 还是 NeoForge、内存给多少、整合包能不能直接整个扔上去。

下面把这条路走一遍。前半段是自己动手的完整流程和几个必踩的坑，后半段讲如果没有一台能 7×24 开着的机器，云上开服大致是什么形态、花多少钱。

## 先分清：NeoForge 和 Forge 不是一回事

NeoForge 是 Forge 的社区分支，主要面向 Minecraft 1.21.x 及更新的版本，安装方式沿用现代 Forge 那套 libraries 机制。1.20.1 以及更早版本的模组生态基本还在 Forge 那边，所以不是「新版本一律用 NeoForge」，而是先看你要玩的整合包/模组支持哪个加载器。

这里有个新手最常踩的坑：

> NeoForge 的 mod 和 Forge 的 mod 不通用。下载前先看 mod 页面标注的加载器，Modrinth 和 CurseForge 的页面都会写清楚。

## 开服前要准备的三件事

**Java 版本**。1.21+ 的 Minecraft 需要 Java 21，1.18–1.20 用 Java 17，1.16 及以下用 Java 8。装错版本的表现通常是启动脚本报一串看不懂的异常，而不是明确告诉你「Java 太老」。

**内存**。社区经验值大致是这样的：100–200 个 mod 给 6–12GB，200–350 个以上给 12–24GB，同时给操作系统留出余量。Minecraft 服务端很吃单核性能，模组一多，单核弱的多核 CPU 反而更吃亏。

**端口**。默认是 25565/tcp。家里开服还得处理路由器端口转发和系统防火墙；云服务器或面板服通常给你的是映射地址（形如 `域名:高位端口`），那就得把 `server.properties` 里的 `server-port` 改成映射端口，否则本地能起、外面连不上。

## 手动搭建：官方安装器这条路

Linux 上整套流程就这几步，Windows 把命令换成对应的 `curl` 和 `run.bat` 即可：

1. 新建一个目录，下载安装器：
   `wget https://maven.neoforged.net/releases/net/neoforged/neoforge/<版本>/neoforge-<版本>-installer.jar`
2. 执行 `java -jar neoforge-installer.jar --installServer`
3. 编辑生成的 `user_jvm_args.txt`，设置 `-Xmx`（最大）和 `-Xms`（初始）
4. 第一次运行 `./run.sh`，它会自己退出来——这一步正常
5. 打开 `eula.txt`，把 `eula=false` 改成 `eula=true`
6. 再启动一次，日志里出现 `Done` 就算起来了

`mods` 目录在第一次启动之后才会出现，把 jar 丢进去即可，mod 建议只从 CurseForge 或 Modrinth 这类可信来源下载。

**整合包要额外处理。** 整合包是第三方启动器的功能，服务端不能直接吃客户端包。如果整合包提供了 server pack，就装一份 server pack 实例；没有的话，装一个普通包实例，再把生成的内容整体移进服务端目录，顺手删掉纯客户端 mod。哪些 mod 属于纯客户端，往往只能试——带光影、资源包功能之类视觉效果的通常是嫌疑对象，删掉后崩溃日志不再报错就算对了。

## 这几个坑，排查表上都有

- `unix_args.txt` 必须放在 `libraries` 根目录，不能留在版本子目录里，放错位置服务端直接起不来。
- `server.properties` 里几项和模组服强相关的：`allow-flight=true`（带飞行坐骑或道具的模组不开这个会被踢出）、`max-tick-time=180000`（模组服启动和生成地形时 tick 很长，默认值容易触发判断为卡死）、`online-mode=false` 时要同步把 `enforce-secure-profile=false`，否则客户端会被拒。
- 首次启动很慢，日志里刷 `Can't keep up!` 一般正常，区块生成跑完就稳定了。
- 升级 NeoForge 或 mod 之前先备份 `world` 目录。更新方式是下载新版本安装器重跑一遍，安装器会替换掉旧版本引用。

## 常见问题

**NeoForge 服务端能装 Forge 的 mod 吗？**
不能。两者加载器互不兼容，装错了表现为启动时报缺失依赖或 mod 直接被跳过。

**1.20.1 该用 NeoForge 还是 Forge？**
1.20.1 的主流模组基本还在 Forge 生态，NeoForge 主要覆盖 1.21.x 及更新版本。先看整合包支持哪个。

**面板服能开整合包服吗？**
能，走「纯 Java 环境」路线：上传服务端包、改端口、替换启动脚本内容。雨云面板的一键开服覆盖 NeoForge 等服务端类型，但整合包本身是第三方打包，需要你手动上传。

**内存不够会怎样？**
不会报错退出，而是 TPS 逐渐下降，玩家感觉到挖方块有延迟、怪物移动一顿一顿的。

**正版验证怎么设？**
购买时面板会让你选在线模式或离线模式，之后也能在文件管理里改 `server.properties` 的 `online-mode`。
